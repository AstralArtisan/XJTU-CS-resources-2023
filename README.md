# XJTU CS Resources · 2023

西安交通大学计算机科学与技术专业的个人课程资料整理，面向 2023 级学习经历。记录大学前三年积累的笔记、练习、实验与复习材料，后续继续补充。

这不是官方课程资源库，也不保证覆盖全部课程或最新教学要求。希望这些学习记录能为后来者提供参考，也欢迎通过 Issue 或 Pull Request 纠错与补充。

## 如何使用

从课程导航进入目录，再阅读课程与实验项目的 README。文件名中的年份、实验编号和章节通常比目录顺序更能说明用途。项目所需环境以其自身说明为准，本合集不提供统一运行环境。

资料沿用现有课程目录和命名；部分课程或章节尚未收集，内容可能不完整。

## 教材下载

9 份完整教材收录在[教材 Release](https://github.com/AstralArtisan/XJTU-CS-resources-2023/releases/tag/materials-2026-10-14)，各课程 README 也提供对应下载链接。教材作为附件单独提供，克隆仓库或下载源码 ZIP 时需另行下载。

## 贡献与纠错

- 指出问题时请提供课程、文件名、页码或代码位置，以及建议修改的原因。
- 新增资料请说明来源、对应学期和使用条件；保留必要的作者及许可信息。
- 提交资料时检查文件名及报告首尾的本人和组员信息，避免附带无关个人信息。
- 不提交真实账户凭据和构建缓存；课程数据、抓包与数据库按其资料来源和使用条件使用。
- 作业与实验用于交流思路，请遵守课程要求并独立完成自己的任务。

## 来源与许可

不同材料可能属于不同作者和许可范围，不能用一个代码开源许可证覆盖全部课件、教材、论文和小组作品。本仓库暂不对全部内容授予统一许可；使用时请遵循具体文件及原项目的许可与来源说明。

教材、课件、论文及小组作品保留现有出处，使用时请根据具体材料的来源和使用条件判断。若发现隐私或来源问题，请在 Issue 中说明文件位置，不要在公开讨论中再次粘贴个人信息。
