## 如何使用

从课程导航进入目录，再阅读课程与实验项目的 README。文件名中的年份、实验编号和章节通常比目录顺序更能说明用途。项目所需环境以其自身说明为准，本合集不提供统一运行环境。

## 贡献与纠错

- 指出问题时请提供课程、文件名、页码或代码位置，以及建议修改的原因。
- 新增资料请说明来源、对应学期和使用条件；保留必要的作者及许可信息。
- 提交资料时检查文件名及报告首尾的本人和组员信息，避免附带无关个人信息。
- 不提交真实账户凭据和构建缓存；课程数据、抓包与数据库按其资料来源和使用条件使用。
- 作业与实验用于交流思路，请遵守课程要求并独立完成自己的任务。

## 关于该仓库、专业学习与保研的一些个人心得

本人能够大方地承认：我的数理能力相当之差劲。因此，在高数、线代、离散、概率论、大物、电路电子这些高学分课程中取得了非常匹配我能力的成绩，从而以最大力度拉低了我的均分。但是我确实是认真学习了这些课，也做了一些笔记吧（有些笔记是纸质的我懒得再拍了），也算有用，可以对复习起到一些帮助。

个人认为我的专业课学习虽然不能算学的最好，但是也应该能说学的还不错了。从大二以来，我尝试自主学习了很多门专业课，网络上的公开课资源与项目练习让我获益匪浅。尽管当今AI的能力已经很强，但是我认为作为计算机专业学生以及未来的从业者，这些基础知识仍需要自己学扎实，融会贯通，不能在基础知识上过度依赖AI，总要有一些自己的理解在。

对于专业课与AI的学习，尽管现在AI浪潮火爆，大家都在转AI方向，但是专业基础课程的重要性仍是不可忽视的。但是在专业课之外，我们也应该持续关注最新的技术变革，保证自己能够持续地跟紧发展，不至于掉队落后太多。AI的更迭速度极快，日新月异，要分辨哪些是噱头，哪些才是真正的发展与革新。同时，自己应该舍得为AI投资，多去尝试各家模型以及不同平台，掌握让AI的工作更加高质量的方法，建立自己的一套工作模式。

[csdiy](https://csdiy.wiki/) 网站收录了大量优秀的课程资源指引，我也是在该网站上利用UCB、CMU等公开课对专业课进行了更加深入的学习。选择这样学习就应该做好付出大量时间精力，却在最后发现对学校考试和自己分数并没有什么帮助的准备，但是我认为这样学习才是对的，这种付出是值得的。如果我在大一的数理课程中取得了更好的成绩足以支持保研，或许就能够拥有更多的时间去进行更多的学习，也是有些悔恨。

关于保研，我想说的是，把每门课都当回事，认真学一学，基本上都是能保的，没有想象中那么困难。如果想要保研，我认为正确的做法是在大一期间尽力将所有数理课程的分数做到能多高有多高，然后在大二期间开始科研训练与专业课的基础学习，最后在大三去尝试联系老师，找到更好的组，达到更好的平台。如果科研上颇有成果，我个人认为出国直博是一个比保研更好的选择。保研是一个持久性的拉练，如果想这样走，那么大学就并不是多么轻松的一段时光，它可能伴随着痛苦、迷茫、压抑与持续的焦虑。能走到最后的人，都值得一份鼓励。相信你们！
