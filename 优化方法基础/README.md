# 优化方法基础

[返回课程总览](../README.md)

- 课程代码：COMP550105
- 开课学期：大三上学期（2025—2026 学年秋季学期）
- 课程性质：推荐选修课
- 授课教师：罗敏楠 教授（计算机科学与技术学院）

优化方法基础是一门偏数学理论与算法的推荐选修课，内容主要围绕凸优化展开，包括凸集与凸函数、对偶与最优性条件、无约束优化、约束优化以及 ADMM 等。课程整体难度适中，课件的结构和主线比较清晰，考前认真复习、把课件里的基本方法和典型题型吃透，通过并不困难；但课程涉及大量推导，对数学基础有一定要求，想拿高分还是需要在平时用心学习，真正理解 KKT 条件、对偶问题以及各类迭代算法的推导与收敛思路，而不能只靠考前突击。

复习时最主要的资料就是罗老师的课件，建议跟着每一章的推导自己动手演算，把无约束优化和约束优化的算法步骤对照着串一遍，最后结合复习课件梳理知识框架。这里收录了 2025—2026 学年秋季学期的授课课件与期末复习资料，供后来的同学参考。
