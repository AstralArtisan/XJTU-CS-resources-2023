# 形式语言与编译

[返回课程总览](../README.md)

形式语言与编译（赵语言），这也是大三下的一枚重磅炸弹了，上过的人都对其赞不绝口，也不乏三届学生同堂的案例，因此建议平时还是学一学，这个课考前突击会很痛苦。由于赵老师的教材和ppt实在难以阅读，所以我建议多询问AI，让AI讲清楚整个课程，然后看一下ppt里面的细节，知道怎么做题就行。26年考试相当阴，题量巨大且题目出现问题，但是赵老师人还是不错的，愿意听学生的建议，最后给分也还可以，希望这个课未来能有所改进吧。

对于形式语言与赵语言之前的编译部分，我参考了哈工大形式语言与自动机MOOC以及Stanford CS143课程，个人认为讲的还是不错的，能够起到一定帮助。

需要提醒的是，考试和往年题以及其他能找到的题型差别很大，不要指望做会这些往年题就上去考试。
