# 数据结构与算法

[返回课程总览](../README.md)

这门课当时我们老师讲的我个人认为比较难以理解，因此学习的是UCB 的 CS61B 课程，这也是我自学的第一次尝试。CS61B 的授课相当之清晰，和计网的CS168是一个老师，且将自编教材笔记、ppt、项目、作业等都开源出来放在课程网页，学习起来很舒适，知道自己应该做什么，目标是什么，学起来很有满足感。推荐尝试学习这门课，对于OOP的学习也有一定帮助。

对于考试，这门课的考试在当年可是相当之阴间，老师出的题故意恶心人，让一个AVL不停地旋转，让一个hash表不停地冲突，真的恶心，做的想吐，不知道以后会是怎样的考试风格。
