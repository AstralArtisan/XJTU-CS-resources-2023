# 软件工程

[返回课程总览](../README.md)

这门课是真的抽象，虽然大部分同学都持正面评价，但是我认为这门课非常的不合理。

首先要说的是因为找不到任何考试的资料，导致我在考前相当焦虑，因此我自己整理出当年的考试题放在这里，希望能帮助到后人。我要说的是：她上课讲的英文ppt是完全没有价值的，在复习时完全不用看。重点放在复习ppt即可，应熟悉所有出现过的题目。

这门课中间还有一个小组项目，要自行设计一个项目，并且按照软件工程知识来分工，并产出相应的报告。这个项目如果要好好做的话，需要耗费大量的时间精力来进行沟通和设计，但是它只占20%，且放在大三下，根本没有多少人愿意好好做，导致这个过程是一个很痛苦的过程。如果对进行一个软件工程的实践感兴趣的话，建议提前沟通好组员情况。
